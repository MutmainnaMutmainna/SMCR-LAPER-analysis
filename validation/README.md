# Expert validation (Table 5)

`aiken_v_by_item.csv` lists Aiken's V for every item that was reviewed by the validators.

- Columns are instrument, item, number of validators, Aiken's V, and whether V reached the 0.70 criterion.
- The rating scale was a four-point scale (1 to 4), and V = sum(rating - 1) / (n x 3).
- The values are those summarised in Table 5 of the article. For the CLASS they describe the initial Indonesian translation.
- Ratings of individual validators are not distributed in this archive.
