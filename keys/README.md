# Answer keys

The answer keys of the original instruments are not distributed with this archive because of the PhysPort distribution restrictions.

To rerun the scoring step, obtain the keys from PhysPort and save them as `keys/answer_keys.xlsx`.

Format: one sheet per instrument (MBT, FMCE, FCI, EMCS, RRMCS, Flip_CoIn), one data row per sheet, the column names are the item names and each cell holds the key letter.

| MBT1 | MBT2 | MBT3 | ... |
|---|---|---|---|
| (option letter) | (option letter) | (option letter) | ... |

For the MBT the item names must match the column names in the Raw_data sheet of the published workbook. For the FCI the item numbers are matched through the trailing digits of the column name (for example FCI1 to FCI30 are used for FCI2-1 to FCI2-30). The file `answer_keys.xlsx` is listed in `.gitignore` so that it is not uploaded by accident.
